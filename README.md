# madeiragabriel.github.io

Academic website of Gabriel Madeira (FGV EBAPE), built with Hugo, Hugo Blox and Pagefind and published with GitHub Pages at https://madeiragabriel.github.io/.

- To add or change content, read `UPDATING.md`.
- To understand how the site is put together (for a developer or an AI assistant), read `WEBSITE_PRINCIPLES.md`.
- Every push to `main` rebuilds and publishes the site automatically (`.github/workflows/deploy.yml`).

Local preview: install Hugo (extended, 0.148.2 or newer) and Node, then `npm install && hugo server`.
